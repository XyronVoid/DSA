# Teji — Paper Trading (Android)

Practice trading NSE stocks, F&O and crypto with virtual money.

- Live NSE prices (Yahoo Finance) and live crypto (Binance trade stream) directly on the phone
- TradingView-style charts with indicators and drawing tools
- Market, Limit, SL-M orders with stop loss and target, holdings, positions and an Orders panel with Exit
- Option chain with payoff graph, journal with stats, 15 lessons with quizzes

Built automatically by GitHub Actions on every push to the `teji-app` branch.
Download: Releases → `teji-latest` → `Teji.apk`.

Practice only. Not investment advice.
